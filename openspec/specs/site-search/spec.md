# site-search Specification

## Purpose
定义站内搜索的可观察行为，确保搜索框不是装饰：输入关键词能真正检索到站内条目，后端不可用时用户能看到明确降级而非静默空结果。

## Requirements

### Requirement: 搜索返回站内条目

站点 MUST 提供一个全文搜索入口，输入关键词后返回与该关键词匹配的文档或博客条目，并能跳转到对应页面。

#### Scenario: 命中已发布内容
- **WHEN** 用户在搜索框输入一个确定存在于已发布文档或博客中的词组
- **THEN** 搜索结果中出现对应的页面标题与链接

#### Scenario: 从结果跳转到原文
- **WHEN** 用户点击某条搜索结果
- **THEN** 浏览器打开该结果对应的站内页面

### Requirement: 搜索后端不可用时有可见降级

搜索依赖外部索引服务时，服务不可用 MUST 让用户看到明确提示，而不是显示「无结果」这一误导性状态。

#### Scenario: 索引服务返回鉴权失败
- **WHEN** 搜索请求因凭据无效被索引服务拒绝
- **THEN** 页面提示搜索当前不可用，且不把失败呈现为零结果

### Requirement: 站点不携带无效凭据

站点 MUST NOT 内置无法通过索引服务校验的搜索凭据。

#### Scenario: 构建产物中的搜索配置有效
- **WHEN** 用站点内置的搜索应用标识与密钥向索引服务发起一次查询
- **THEN** 索引服务接受该凭据并返回查询结果，而非鉴权错误
