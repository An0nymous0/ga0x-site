# Spec Delta

## Purpose

定义站点页脚的身份与合规展示契约：站点名、版权年份、ICP 备案号及其跳转目标，确保备案信息按规范展示且不混入模板残留内容。

## ADDED Requirements

### Requirement: 页脚展示站点身份与年份

页脚 MUST 展示站点名称与当前年份，构成版权声明。

#### Scenario: 年份随构建时间更新
- **WHEN** 站点在任意年份构建
- **THEN** 页脚版权行显示的年份等于构建时的年份

#### Scenario: 不残留模板占位内容
- **WHEN** 检查已发布页面的页脚
- **THEN** 其中不包含脚手架模板遗留的组织名占位文本

### Requirement: 页脚展示 ICP 备案号并链接备案系统

页脚 MUST 展示有效的 ICP 备案号，且该备案号 MUST 链接到工业和信息化部备案管理系统。

#### Scenario: 备案号可见且可点击
- **WHEN** 用户访问任一已发布页面并滚动到页脚
- **THEN** 页脚显示备案号文本，点击后在新窗口打开备案管理系统

#### Scenario: 备案号出现在全站页面
- **WHEN** 用户访问站内任意已发布路由
- **THEN** 该页面的页脚都包含同一个备案号

#### Scenario: 备案号紧随站点名
- **WHEN** 检查页脚版权行
- **THEN** 备案号出现在站点名称之后，不与任何第三方组织名混排
